## ✨ Key Features

- **🔒 100% Client-Side Privacy**: All AI processing (face detection & background removal) runs locally in your browser using WASM and GPU acceleration. No server uploads.
- **🤖 AI Background Removal**: Instant magic background removal powered by MediaPipe Image Segmentation.
- **🎯 Smart Face Detection**: Automatically detects and crops faces to perfect passport dimensions (35x45mm) with ICAO compliance checks.
- **🎨 Pro Enhancements**: Adjust brightness, contrast, saturation, sharpness, and warmth with real-time preview.
- **🖨 Print-Ready Layouts**: Generate A4 sheets with multiple photos, cut marks, and custom borders.
- **📱 Responsive Design**: Fully optimized for Mobile, Desktop, Tablets, and iPads.
- **🌐 SEO Optimized**: High-ranking keywords in English and Hinglish to reach a global audience.

## 🛠️ Tech Stack & Architecture

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **AI Engine**: [MediaPipe Tasks-Vision](https://developers.google.com/mediapipe/solutions/vision)
- **Styling**: Vanilla CSS (Modern CSS Modules)
- **Performance**: WebAssembly (WASM), GPU Delegation, and Object URL previews.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- NPM or Yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/NikhilCodeWorks/passphoto-studio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
